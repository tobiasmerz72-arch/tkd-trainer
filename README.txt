TOBI'S TAEKWON-DO ACADEMY — VERSION 4.0

NEW IN THIS VERSION
- New Academy name and redesigned home/settings screen
- Your Taekwon-Do martial-artist image is used as the hero artwork
- Large touch-friendly Practice tiles
- Common Terms, Techniques and Theory remain separate practice types
- Technique practice displays only the belt, never Kick/Block/Stance categories
- Theory questions and answers automatically use smaller text when required
- Long theory answers can scroll inside the card so no text is cut off
- Swipe-first behaviour remains:
  * Common Terms / Techniques: swipe left for next
  * Theory: swipe left to reveal, swipe left again for next
  * Tap or swipe right reveals/hides the answer
- Right and Wrong buttons remain optional
- Offline service worker retained
- Wrong-answer review retained
- Settings and wrong cards are stored on the device
